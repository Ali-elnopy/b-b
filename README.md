# يوزرسيف — للطباعة والهدايا

موقع تعريفي كامل + لوحة تحكم لإدارة الطلبات، مبني على **React 19 + Vite** للواجهة و**Express 5 + SQLite** للـ API.

- واجهة عربية RTL بخط Zain وهوية يوزرسيف (أخضر دائم / تيل / ثلجي).
- ٨ خدمات طباعة وهدايا مع صفحة تفاصيل لكل خدمة.
- طلب أونلاين من ٥ خطوات مع رفع الملفات وفحص الجاهزية.
- تتبع الطلب برقم الطلب فقط.
- لوحة تحكم: نظرة عامة، الطلبات، الخدمات، الأعمال، الإعدادات، سجل النشاط.

## المتطلبات

- **Node.js 22 أو أحدث** (المشروع يستخدم `node:sqlite` المدمج — لا يوجد أي اعتماد أصلي يحتاج بناء).
- npm 10+.

## التشغيل السريع

```bash
npm install
npm run build
npm start
```

ثم افتح: <http://127.0.0.1:4100>

`npm start` يقدّم الـ API والواجهة المبنية (`dist`) من نفس السيرفر على المنفذ **4100**.

### وضع التطوير

```bash
npm run dev
```

- الواجهة: <http://127.0.0.1:5173>
- الـ API: <http://127.0.0.1:4100>
- Vite يمرّر طلبات `/api` و`/media` تلقائيًا إلى الـ API (انظر `vite.config.js`).

## الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | تشغيل API + Vite معًا |
| `npm run build` | بناء الواجهة إلى `dist/` |
| `npm start` | تشغيل السيرفر (يقدّم `dist` إن وُجد) |
| `npm test` | اختبارات منطق الجاهزية والحالات (11 اختبار) |
| `npm run seed` | إعادة تهيئة البيانات التجريبية (`--force` لمسح الحالي) |
| `npm run media` | إعادة معالجة الصور إلى `public/media` |

## متغيرات البيئة (اختيارية)

| المتغير | الافتراضي | ملاحظة |
| --- | --- | --- |
| `PORT` | `4100` | منفذ السيرفر |
| `NODE_ENV` | — | `production` يفعّل CSP وتخزين مؤقت أطول |
| `CLIENT_ORIGIN` | `localhost:5173` | أصول مسموحة للـ CORS/CSRF مفصولة بفاصلة |
| `YOZ_DB_PATH` | `server/data/yozersaf.db` | مسار قاعدة البيانات |
| `YOZ_DATA_DIR` | `server/data` | مجلد البيانات |
| `YOZ_UPLOAD_DIR` | `server/uploads` | مجلد مرفقات العملاء |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` / `ADMIN_NAME` | قيم seed | تُستخدم عند إنشاء حساب المالك أول مرة |

## بنية المشروع

```
├─ src/                 واجهة React
│  ├─ pages/            صفحات الموقع العام
│  ├─ admin/            صفحات لوحة التحكم
│  ├─ components/       مكوّنات مشتركة (Layout، Icons، Common)
│  ├─ context/          Site / Auth / Toast
│  ├─ styles/           base, site, admin, extra
│  └─ lib/              api client + تنسيقات
├─ server/              Express API
│  ├─ api.js            المسارات العامة ولوحة التحكم
│  ├─ db.js             المخطط واتصال SQLite
│  ├─ seed.js           الإعدادات والخدمات والأعمال التجريبية
│  ├─ auth.js           الجلسات وتجزئة كلمات المرور
│  ├─ data/             قاعدة البيانات (SQLite)
│  └─ uploads/          مرفقات الطلبات
├─ shared/              منطق مشترك (readiness, status, services)
├─ public/media/        صور ووسائط الموقع المحسّنة
├─ tests/               اختبارات node:test
├─ scripts/             أدوات بناء الوسائط والفحص
└─ index.html, vite.config.js
```

## ملاحظات مهمة

- الإعدادات تحتوي `demoMode: true` و`launchApproved: false` — المشروع جاهز للعرض، وليس مُعلنًا للإطلاق التجاري.
- بعض الأعمال في المعرض نماذج (isDemo) وتظهر بشارة «نموذج» وتنبيه واضح.
- نموذج «تواصل معنا» يجهّز رسالة واتساب ولا يرسل بريدًا (لا يوجد تكامل بريد).
- رفع الملفات يقبل PDF / PNG / JPG / SVG / AI / PSD / ZIP حتى حجم محدد لكل ملف، مع فحص على السيرفر.
- النسخ الاحتياطي = نسخ `server/data/yozersaf.db` و`server/uploads/`.
- مجلدات المصادر الثقيلة (`website/`, `assets-src/`, ملفات PNG/PDF الأصلية) غير مضمّنة في الأرشيف لتقليل الحجم؛ الصور المستخدمة فعليًا موجودة في `public/media/`.
